# Leaderless Graph Based Task Orchestration

This example demonstrates a leaderless, graph-based orchestration approach for multi-agent systems. Tasks (agents) coordinate their execution based on a predefined dependency graph, where each agent independently checks the status of its prerequisites before proceeding. This eliminates the need for a central coordinator, showcasing a more scalable and flexible system design.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
